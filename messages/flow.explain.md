# summary

Explain the stored configuration and paths of a Flow element.

# description

Show element conditions, assignments and other configuration with metadata paths, resource references and outgoing connectors. This command does not use AI, execute the Flow or predict which condition will pass.

# examples

- sf flow explain --source-file force-app/main/default/flows/My_Flow.flow-meta.xml --element Check_Account

# flags.element.summary

Exact element API name, or start.
